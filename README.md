# tais-website
Website for the Tennessee Alternative Investments Society

The Tennessee Alternative Investments Society (TAIS) prepares University of Tennessee students for careers in private equity, hedge funds, equity research, investment banking, and asset management. We're recruiting our founding class this spring.
